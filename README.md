# 国家宏观金融体系模拟器 (Financial System Macro Simulator) - MVP

基于宏观经济学与金融回路构建的文字交互式模拟器。玩家扮演国家决策层（央行/财政部），接管一个深陷泥潭的困难国家，通过利率杠杆、财政税收调节以及推行历史上著名的战略政策卡，尝试带领国家走出困境，实现六维指标的可持续发展。

---

## 🌟 核心设计理念

1. **动态自洽的稳态陷阱（零干预测试）**：
   - 如果玩家不进行任何外部干预，整个国家经济处于一个**困难标准的动态平衡状态**。
   - 包含内生稳定器（劳动力粘性、生存底线消费、银行净息差覆盖不良坏账、赤字自动通过国债平抑），在 10 年（3600天）无干预测试中**不发生恶性通胀或金融崩盘，微幅波动稳定运转**。

2. **全穿透资金流账本（钱从哪来，到哪去）**：
   - 彻底拒绝凭空刷钱。
   - 每一笔交易（政府采购、企业投资、工资发放、信贷利息、国税征收、居民食物开销）都有清晰的资金流向溯源，随时可在穿透账本中查询。

3. **六维民生与宏观雷达指标**：
   - **整体年化 GDP**：衡量国家总生产与总需求规模 ($C + I + G$)。
   - **人均年化 GDP**：衡量人均生产力水平。
   - **恩格尔系数**：食物必需品支出 / 总生活消费支出（困难开局约 58%~60%）。
   - **贫困人口占比**：日均可支配收入低于生存红线的人口比例（困难开局约 40%~43%）。
   - **社会失业率**：未就业劳动力比例（困难开局约 18%~22%）。
   - **居民消费意向**：全社会敢于花钱的信心指数（0~100）。

4. **朝令夕改惩罚（政策公信力机制）**：
   - 允许随时暂停调整宏观参数，但若在 30 天内频繁微调，将受到“政策公信力”的严厉惩罚。
   - 公信力低会导致银行上浮贷款风险溢价、企业冻结中长期资本开支、居民避险削减消费。

5. **三张经典历史名策卡（首批已装配）**：
   - **【罗斯福新政·以工代赈】**（凯恩斯主义）：国库专项发债出资，政府直接雇佣 45 万底层失业者，大幅压低失业与贫困，但增加国家债务。
   - **【里根大减税·供给学派】**（供给学派）：大幅削减企业所得税至 12%，留存利润全部激励企业扩大再投资，GDP 爆发式增长，但底层贫困率改善微弱（K型分化）。
   - **【直升机撒钱·普惠现金】**（现代货币理论）：央行直接印钞，每人每日发放现金支票，恩格尔系数与贫困率瞬间剧降，消费意向飙升，但潜在通胀压力增大。

## 🚀 快速启动

### 1. 运行图形化 Web 网页版 (推荐)
```bash
python3 web_server.py 8080
```
* 本地浏览器直接访问：**`http://localhost:8080`**
* 包含实时可交互六维雷达图、六大指标动态卡片、时间播放器、杠杆滑动条、政策卡签署/废除、穿透流水表格与历史季度决算报表。

### 2. 运行交互式终端命令行版
```bash
python3 main.py
```
* 纯终端文字交互与 ASCII 仪表盘。

### 3. 运行 10 年（3600天）无干预稳态基准测试
```bash
python3 verify_stability.py
```
* 输出 10 年间每隔关键节点的六维数据与财政金融指标，验证系统稳态运转能力。

### 3. 运行三张政策卡对比测试
```bash
python3 test_cards.py
```
* 自动对比三张历史政策卡生效时对六维指标的差异化冲击与资金流向。
